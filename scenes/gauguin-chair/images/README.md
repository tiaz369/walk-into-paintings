# 高更的椅子的图片

- `gauguin-chair.jpg`：梵高《高更的椅子》1888，阿姆斯特丹梵高博物馆藏（s0048V1962，文森特·梵高基金会）。公有领域（PD-Art），来自 Wikimedia Commons 的 Google Art Project 版本：
  https://commons.wikimedia.org/wiki/File:Vincent_van_Gogh_-_De_stoel_van_Gauguin_-_Google_Art_Project.jpg
  和《梵高的椅子》场景里的 `gauguin-chair.jpg` 是同一个文件（Tia 2026-10-27 上传，1280 × 1599），这里缩到 1024 × 1279，不超过 500KB。
  房间、椅子、蜡烛、书和煤气灯的位置是照着这张图算的。
- 不从梵高博物馆官网或 Google 艺术与文化下载。
- `crops/floor.jpg`、`crops/wall.jpg`：从 `gauguin-chair.jpg` 裁出的地面和墙，用来铺画面以外的房间。
