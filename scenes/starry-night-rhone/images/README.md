# 罗纳河上的星夜的图片

请从 Wikimedia Commons 下载后上传到这个文件夹（每张不超过 25MB，选 "Other resolutions" 里约 2000 像素宽的版本）：

- `starry-night-rhone.jpg`：梵高《罗纳河上的星夜》1888年9月，巴黎奥赛博物馆藏。Commons 文件名 "Starry Night Over the Rhone.jpg"，公有领域。
- `starry-night-1889.jpg`：梵高《星夜》1889，纽约现代艺术博物馆藏（独家发现“两个星夜”和第三幕用）。Commons 文件名 "Van Gogh - Starry Night - Google Art Project.jpg"，公有领域。
