# 原画图片 / Painting images

把这 2 张图片放在这个文件夹里（文件名必须完全一样，全小写）：

| 文件名 | 内容 |
|---|---|
| `v1888.jpg` | 《阿尔勒的卧室》1888年版 · 阿姆斯特丹梵高博物馆 |
| `v1889-chicago.jpg` | 1889年版 · 芝加哥艺术博物馆 |

建议宽度约 2000 像素。

`crops/` 文件夹里是从 v1888.jpg 裁剪、拉正的墙上小画和镜子（两幅肖像、两幅小画、风景画、镜子），3D 房间里的画框会用到。

奥赛博物馆的 1889 年小幅版：照片版权属于奥赛博物馆（© Musée d'Orsay, Dist. RMN-Grand Palais / Patrice Schmidt），所以不放在网站上，结尾里改为链接到奥赛官网的作品页。
