# 苦艾酒（在咖啡馆里）：资料来源

所有事实文字由 Tia 提供（资料来自奥赛博物馆官网）。

- 奥赛博物馆：Dans un café, dit aussi L'Absinthe（RF 1984，1875–1876，92 × 68.5 cm）https://www.musee-orsay.fr/fr/oeuvres/dans-un-cafe-1147
- 维基百科 https://en.wikipedia.org/wiki/L%27Absinthe

没有写进页面的：
- 有资料说这幅画让两位模特被误认为酒鬼，德加不得不公开澄清；也有当时的评论家写过很难听的话。这些来源不够可靠，或者对画中人物不尊重，所以没有放进来。
- 这幅画涉及饮酒：卡片里只描述画面和历史，不做道德评判。
