# 图片

- `moulin-galette.jpg`：雷诺阿《煎饼磨坊的舞会》，1876年，巴黎奥赛博物馆（RF 2739）。Tia 2026-10-27 从 Wikimedia Commons 下载的公有领域（PD-Art）版本（https://commons.wikimedia.org/wiki/File:Pierre-Auguste_Renoir,_Le_Moulin_de_la_Galette.jpg ，上传的文件 IMG_0530.jpeg），1920 × 1430 像素。没有用奥赛官网或 RMN 的图片。
