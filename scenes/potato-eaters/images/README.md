- 之前用的是梵高博物馆官网的图（只限非商业使用），按版权规则换掉了。
- `potato-eaters-kroller-muller.jpg`（可选，还没上传）：克勒勒-米勒博物馆藏的早期版本，独家发现“三个版本”用。
